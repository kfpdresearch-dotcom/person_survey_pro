## 2. 무엇이 들어가 있나

기존 진단(문항 → 채점 → 생활신호 74종 → 맞춤 서비스 34종)은 **그대로**이고, 결과 화면 「맞춤 서비스」 탭에서 `track` 태그로 갈라집니다.

```
진단(기존) → 프로파일 정규화 → 자격 대조·우선순위 → track 분기
   ├─ TRACK B 공공서비스 신청 돕기
   │    신청 가능성 3단계(신청 가능/확인 필요/해당 없음 + 이유 한 줄)
   │    → 신청 정보 → 준비물·작성 도우미 → 신청 페이지 열기 또는 서식·묶음 PDF → 신청 확인
   └─ TRACK A 민간 기관·동네 프로그램
        A-돌봄: 장기요양기관(공식 평가 지표, 거리/평가등급/정원 여유 정렬)
        A-생활: 노인복지관·경로당·평생학습 강좌
             ↓
   합류 「우리 어르신 돌봄 계획」 — 연락할 곳 + 신청할 제도와 순서 + 이번 주 할 일 1개
```

## 3. ★ 공공데이터 — 이번에 확인한 것 (다시 찾지 마세요)

### 3-1. 요청주소 6개 — 전부 확인 완료

`tools/collect/endpoints.json` 에 반영돼 있고 `verify` 플래그는 전부 `false` 입니다.

| 용도 | 요청주소 |
|---|---|
| 장기요양기관 검색 (15059029) | `https://apis.data.go.kr/B550928/searchLtcInsttService02/getLtcInsttSeachList02` |
| 입소인원 정원·현원 (15058856) | `https://apis.data.go.kr/B550928/getLtcInsttDetailInfoService02/getAceptncNmprDetailInfoItem02` |
| 중앙부처 복지 목록 (15090532) | `https://apis.data.go.kr/B554287/NationalWelfareInformationsV001/NationalWelfarelistV001` |
| 중앙부처 복지 상세 | `.../NationalWelfareInformationsV001/NationalWelfaredetailedV001` |
| 지자체 복지 목록 (15108347) | `https://apis.data.go.kr/B554287/LocalGovernmentWelfareInformations/LcgvWelfarelist` |
| 지자체 복지 상세 | `.../LocalGovernmentWelfareInformations/LcgvWelfaredetailed` |

**확인 방법** — 키 없이 호출했을 때 응답코드로 구분됩니다.
`returnReasonCode 30` (SERVICE_KEY_IS_NOT_REGISTERED) = 주소가 맞고 키만 없음 / `12` (NO_OPENAPI_SERVICE) = 없는 주소.
포털 Swagger 화면에서도 `Base URL: apis.data.go.kr/B550928/searchLtcInsttService02` · `GET /getLtcInsttSeachList02` 로 재확인했습니다.

### 3-2. 입소인원 응답 필드 — 공식 활용가이드에서 확정

| 필드 | 뜻 |
|---|---|
| `totPer` | 정원 |
| `maNowPer` | 현원_남 |
| `fmNowPer` | 현원_여 |
| `maRsvPer` / `fmRsvPer` | 대기_남 / 대기_여 |

**현원 = `maNowPer` + `fmNowPer`** 입니다. 기존 설정에 있던 `nowPer` 는 존재하지 않는 필드였습니다.
요청 파라미터는 `longTermAdminSym`(필수), `pageNo`, `numOfRows`.
수집할 때 `--detail` 플래그를 주면 기관마다 1건씩 더 받아 채웁니다.

### 3-3. 시설별 상세조회 9개 오퍼레이션

`endpoints.json` 의 `ltc_detail.operations` 에 전부 기록돼 있습니다.

```

인력현황   getStaffSttusDetailInfoItem02
시설현황   getInsttSttusDetailInfoItem02
입소인원   getAceptncNmprDetailInfoItem02   ← 정원·현원
```

### 3-4. 공식 활용가이드 받는 법

포털 상세 페이지 HTML 에서 `fn_fileDownload('FILE_...','1')` 을 찾아:

```bash
curl -sSL -A "Mozilla/5.0" -e "https://www.data.go.kr/data/15058856/openapi.do" \
  "https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003612293&fileDetailSn=1" \

```

→ `(활용가이드)장기요양기관 시설정보_수정.docx` (1.2MB). docx 라 `zipfile` 로 `word/document.xml` 을 뜯으면 표가 다 나옵니다.

## 4. 남은 일 — 인증키 두 개

### 4-1. 받아야 할 것

| 키 | 받는 곳 | 비고 |
|---|---|---|
| `DATA_GO_KR_KEY` | [data.go.kr](https://www.data.go.kr) 로그인 → 15059029 / 15058856 / 15090532 / 15108347 각각 **활용신청** → 마이페이지 > 데이터활용 > Open API > 인증키 발급현황 | **Decoding 키**. 계정당 하나로 전부 사용. 자동승인 |
| `KAKAO_REST_KEY` | [developers.kakao.com](https://developers.kakao.com) → 앱 만들기 → REST API 키 | 주소→좌표용. 하루 10만 건 무료 |

**파일 데이터 3종** (신청 없이 내려받기, 엑셀로 열어 **CSV UTF-8** 로 저장)

- 장기요양기관 평가 결과 (15104801) — 평가등급·총점·영역별 점수
- 전국평생학습강좌 표준데이터 — 동네 강좌
- 노인복지 이용시설 현황 (15098828) — 복지관·경로당

### 4-2. 넣고 돌리기

```bash
cp tools/collect/.env.example tools/collect/.env     # 키 두 개 붙여넣기 (.gitignore 에 있음)

node tools/collect/collect.mjs --verify              # ① 응답 필드명 대조 (API당 1건만 호출)
node tools/collect/collect.mjs --sido 41 --ltc --welfare --detail \
  --eval 평가결과.csv --courses 평생학습강좌.csv --places 노인복지시설.csv   # ② 수집

# 윈도우
tools\collect\run.cmd --verify
.\tools\collect\run.ps1 --sido 41 --ltc --welfare
```

- `--verify` 는 응답 필드명이 `endpoints.json` 과 다르면 **비슷한 이름 후보를 찾아 알려줍니다.**
- 수집하면 `data/` 가 교체되고 화면의 **「예시 데이터」 표시가 자동으로 빠집니다.**
- 중앙부처 복지서비스는 **일 100건** 제한 → 한도에서 멈췄다가 다음 날 이어서(`.progress.json`).
- **경기도(41) 한 곳부터** 수집해 화면 확인 후 전국으로 넓히는 것을 권합니다.

## 5. 작업 환경 제약 (새 세션에서 먼저 확인할 것)

| 항목 | 상태 | 확인 방법 |
|---|---|---|
| `apis.data.go.kr` · `dapi.kakao.com` · `www.data.go.kr` | **허용됨** (2026-11-03 추가) | `curl -sS -o /dev/null -w "%{http_code}" https://www.data.go.kr/` → 200 |
| `*.github.io` | **차단** — Pages 링크를 작업 공간에서 열어 확인 불가 | 사람이 브라우저로 확인해야 함 |
| GitHub 푸시 | **가능** (GitHub App 설치됨) | `git push --dry-run` |
| GitHub GraphQL (`gh pr create`) | **차단** — REST 로 우회 | `gh api repos/{o}/{r}/pulls --method POST --input pr.json` |
| GitHub Pages API | **차단** | `gh api repos/{o}/{r} --jq .has_pages` 로 대체 |

> 도메인 허용은 claude.ai → 설정 → Capabilities 에서 설정합니다.

### 얕은 복제 주의

`--depth 1` 로 받으면 원격추적 ref 가 안 생겨 "미푸시 커밋 있음" 오탐이 납니다. 푸시 후:

```bash
git fetch origin BRANCH:refs/remotes/origin/BRANCH --depth=1
git config branch.BRANCH.remote origin
git config branch.BRANCH.merge refs/heads/BRANCH
```
